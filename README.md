# GWAN-GANG

**관광통역안내사 1차 벼락치기** — 2026년 제1차 필기시험(2026-09-05)을 위한
모바일 우선, 로컬 전용 적응형 훈련 앱.

목표는 하나입니다. **9월 5일에 한 문제라도 더 맞히는 것.**
그래서 이 앱은 "무엇을 공부할까?"를 학습자가 고민하지 않도록 만들어졌습니다.
앱을 열고 → 버튼 하나 누르고 → 문제를 풀고 → 약점이 갱신되고 → 다음 문제가 더
정확해집니다.

## 시험 구조

| 과목 | 문항 | 배점 | 문항당 환산점수 |
| --- | --- | --- | --- |
| 관광국사 | 25 | 40% | **1.6점** |
| 관광자원해설 | 25 | 20% | 0.8점 |
| 관광법규 | 25 | 20% | 0.8점 |
| 관광학개론 | 25 | 20% | 0.8점 |

- 총 100문항 / 100분
- **합격 = 가중 총점 60점 이상 AND 전 과목 40%(25문항 중 10문항) 이상**
- 총점이 60점을 넘어도 한 과목이 9문항이면 **과락으로 불합격**입니다.

이 규칙은 `src/lib/scoring.ts` 한 곳에만 존재하며 단위 테스트로 고정되어 있습니다.
어떤 화면도 자체 점수 공식을 갖지 않습니다.

### 적응형 선택

설명 가능한 휴리스틱입니다. 학습 모델이 아닙니다.

```
우선순위 = 취약도 × 경과시간 × 과목배점 × 오답유형 × 확신도 × 복습도래 × 노출감쇠
```

- 관광국사는 배점이 2배이므로 `×2.0`
- 오답 유형: 헷갈림 `×1.8` > 몰랐음 `×1.5` > 실수 `×0.8`
- 복습 도래 `×2.5`, 최근 15분 내 푼 문제는 보류
- 우선순위 가중 무작위 추출 — 같은 세션이 반복되지 않습니다

### 짧은 복습 주기 (6일용, Anki 아님)

| 오답 유형 | 간격 |
| --- | --- |
| 헷갈림 | 5분 → 3시간 → 다음날 → 이틀 뒤 |
| 몰랐음 | 10분 → 6시간 → 다음날 → 이틀 뒤 |
| 실수 | 다음날 → 이틀 뒤 |

맞히면 다음 단계로, 틀리면 처음으로 되돌아갑니다.

## 점수 표시 원칙

- 표시되는 값은 **"현재 훈련 기준 점수"**이지 합격 확률이 아닙니다.
  근거 없는 확률(`합격확률 83.7%` 같은)은 표시하지 않습니다.
- 추정치는 **과목별 최근 최대 50문항**을 최신 가중치로 계산합니다.
  단순 누적 정답률이 아닙니다.
- 어떤 과목이든 근거가 8문항 미만이면 **`데이터 부족`**이라고 말합니다.
  숫자를 지어내지 않습니다.
- **개발용 샘플 문제는 점수에 절대 반영되지 않습니다.**
- 과락 위험은 총점과 독립적으로 항상 표시됩니다.

## 문제은행 · 출처 표기

문제은행은 저장소에 포함되어 있지 않습니다. → **[docs/question-import.md](docs/question-import.md)**

- JSON / CSV 가져오기, 행 단위 검증, 중복 id 처리
- 모든 문제는 출처(`sourceType`)가 **필수**이며 화면에 배지로 항상 표시됩니다
  (`기출` · `공식자료` · `사용자 입력` · `AI 변형` · `교재 기반` · `샘플`)
- **AI 생성 문제와 샘플은 언제나 `미검증`으로 강제**됩니다. 파일에 `verified`라고
  적혀 있어도 마찬가지입니다.
- **실전 모의고사는 기본적으로 검증된 문제만** 사용합니다. 부족하면 빈 자리를
  채우지 않고 몇 문제가 부족한지 그대로 알려줍니다.

### 저작권

보유한 시판 교재(시대에듀 등)의 내용을 이 저장소에 넣지 마세요. 스캔·OCR 덤프·
챕터 전문·문제은행 복제는 포함하지 않습니다. 학습자가 자신의 브라우저에 개념 정리나
짧은 발췌를 개인적으로 입력하는 것은 별개이며, 그 데이터는 로컬에만 남습니다.

## 로컬 저장 · 백업

- 모든 데이터(문제, 시도, 오답, 복습 일정, 모의고사, 메모, 설정)는
  **IndexedDB**에 저장됩니다. 서버도, 계정도, 로그인도 없습니다.
- 새로고침·탭 종료·앱 전환 후에도 진행 중인 세션과 모의고사가 복구됩니다.
  모의고사 타이머는 시작 시각 기준 실제 시간으로 흐르므로 새로고침으로 시간을
  벌 수 없습니다.
- **데이터 → 데이터 내보내기 / 가져오기**로 JSON 백업을 주고받을 수 있습니다.
  복원 시 형식이 깨진 행만 건너뛰고 나머지는 살립니다.
- **학습기록 초기화**는 확인 절차를 거칩니다.

## AI 학습 브릿지

GWAN-GANG은 챗봇을 만들지 않습니다. 대신 **지금의 약점 상태를 다른 AI 튜터에
넘기는 프롬프트**를 만들어 줍니다. API 키도, 네트워크 호출도 필요 없습니다.

| 대상 | 내용 |
| --- | --- |
| **ChatGPT Study Mode** | 15~25분, 한 번에 한 문제씩, 약점 주제 집중, 몰랐음/헷갈림 구분 |
| **Gemini Study Notebook** | 20~30분, 업로드 자료 기반 진단 → 한 입 설명 → 즉시 재테스트 |
| **NotebookLM** | 주제 수준의 Markdown 스냅샷 (문제 본문·교재 원문 미포함) |
| **문제 생성** | GWAN-GANG 스키마의 JSON만 출력하도록 강제하는 출제 프롬프트 |

생성된 문제는 다시 **데이터 → JSON 붙여넣기**로 가져오면 됩니다.
`GWAN-GANG → 약점 → LLM → 표적 문제 → GWAN-GANG` 왕복이 연동 없이 완성됩니다.

## PWA

`manifest.webmanifest` + 서비스 워커로 홈 화면 설치와 오프라인 앱 셸을 지원합니다.
문제 데이터는 IndexedDB에 있으므로 비행기 모드에서도 학습이 됩니다.
아이콘은 `scripts/make-icons.mjs`가 생성하며 외부 폰트·에셋 의존성이 없습니다.

## 배포

Vercel용 정적 SPA입니다. `vercel.json`에 프레임워크(vite), 출력 디렉터리(`dist`),
SPA 리라이트, 캐시 헤더가 들어 있습니다.

```bash
npm run build     # dist/ 생성
vercel --prod     # 또는 GitHub 연동 후 자동 배포
```

환경 변수도 비밀 값도 필요 없습니다.

## 아키텍처

```
src/
  lib/
    exam.ts        시험 구조 상수 (과목·배점·문항수·시험일)  ← 단일 진실 공급원
    scoring.ts     가중 점수 · 합격 판정 · 과락 · 점수 구간
    estimate.ts    최근 기록 기반 훈련 점수 추정 (데이터 부족 처리 포함)
    leverage.ts    65점/70점까지 필요한 추가 정답 조합 계산
    adaptive.ts    우선순위 휴리스틱 · 과목 배분 · 세션 구성
    review.ts      6일용 짧은 복습 사다리
    mock.ts        모의고사 구성(과목당 25) · 채점
    weakness.ts    주제별 취약도 · 오답 유형 분포
    import.ts      JSON/CSV 가져오기 + 행 단위 검증
    backup.ts      백업 내보내기/복원
    studyPack.ts   AI 학습 브릿지 프롬프트 생성
    schema.ts      zod 스키마 (출처 보장 규칙 포함)
    db.ts          IndexedDB
    store.ts       zustand 스토어 (메모리 + 즉시 영속화)
  routes/          화면
  components/      공용 UI
  data/            개발용 가상 샘플 문제
```

**설계 원칙**

- 로컬 우선. 백엔드 없음, 계정 없음, 네트워크 왕복 없음.
- 점수 규칙은 한 곳에만. 화면은 계산하지 않고 표시만 합니다.
- 정확성 > 분량. 검증 못 한 시험 내용은 만들지 않습니다.
- 주의력은 희소 자원. 화면당 명확한 다음 행동 하나.
- 상태는 항상 복구 가능해야 합니다.

프레임워크는 Next.js가 아닌 **Vite + React SPA**입니다. 서버 렌더링이 필요 없고,
D-day와 IndexedDB 상태에 의존하는 화면에서 하이드레이션 불일치가 생길 여지를
없애기 위해서입니다. Vercel 배포 호환성은 동일합니다.
